# SA Gesetzbuch

Durchsuchbare Sammlung der Gesetze des Staates San Andreas (GTA-Roleplay-Server LuckyV.de).

**Live-Seite:** https://raccoonscityttv.github.io/sa-gesetzbuch/

## Enthalten

| Gesetzbuch | Stand |
| --- | --- |
| Constitution of San Andreas (Landesverfassung) | 04.07.2026 |
| Penal Code San Andreas (PCSA) | 26.08.2026 |
| Code of Criminal and Civil Procedure (CCCP) | 15.04.2026 |
| Traffic Code | nicht angegeben |
| Zivil- und Handelsgesetze | nicht angegeben |
| Code of State Regulations (Landeserlasse) | 04.07.2026 |

## Funktionen

- Volltextsuche über alle Paragraphen (umlaut-tolerant, auch nach Nummer wie `6.02`)
- Filter nach Gesetzbuch und Inhaltsverzeichnis
- Strafkatalog mit Geldstrafen und Hafteinheiten, filterbar nach Verkehr, Citation, Misdemeanor, Felony
- Zitat per Klick kopieren (z. B. `PCSA Sec. 6.02 – Körperverletzung`)
- Direktlinks auf Paragraphen (`#pcsa-6-02`)

## Aufbau

- `index.html` – die komplette Seite, Gesetzesdaten sind eingebettet
- `data/gesetze.md` – Gesetzestexte als Markdown (Quelle)

Inoffizielles Fan-Projekt, nicht mit LuckyV.de verbunden. Maßgeblich ist immer der aktuelle Stand im Justiz-Bereich von LuckyV.de.
